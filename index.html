多元線性迴歸 (Multiple Linear Regression) 核心原理與 50 Startups 統計洞察

理解從資料矩陣到閉式解 (Closed-form Solution) 的數學機制

1 最小平方法與正規方程式 (OLS)

線性迴歸旨在最小化所有樣本殘差平方和：
Loss = Σ(yᵢ - ŷᵢ)² = ||y - Xw||²

對權重向量求梯度並令其為零，即可解出不需要迭代的全局最佳解析解：
w* = (XᵀX)⁻¹ Xᵀy
本工具中的「一鍵最佳解」即在前端以純 JavaScript 透過高斯-約當消去法實時計算此矩陣反矩陣！

2 為什麼研發支出 (R&D) 決定一切？

在 50 Startups 資料集中，研發支出與利潤的 Pearson 相關係數高達 r = 0.973。

即便僅使用單一特徵「研發支出」，決定係數 R² 就已經高達 0.9465。 而加入管理支出 (Administration) 與行銷支出後，R² 僅微幅提升至 0.9507。 這揭示了企業創新技術研發是獲利的絕對主導驅動力。

3 管理支出的多重共線性與 P 值

在完整的 3 特徵模型中，管理支出的係數約為 -0.0268，但其假說檢定的 P-value 高達 0.6 以上（遠大於顯著性標準 0.05）。

在統計模型中，這意味著「管理支出對利潤的線性貢獻在統計上不顯著」，在後向剔除法 (Backward Elimination) 或 Lasso 懲罰迴歸中，管理支出往往是第一個被篩選剔除的特徵。

多元線性迴歸評估指標計算公式

1. 決定係數 (R-Squared, R²)
R² = 1 - (SS_res / SS_tot) = 1 - [Σ(yᵢ - ŷᵢ)² / Σ(yᵢ - ȳ)²]

衡量模型自變數能解釋目標變數總變異量 (Variance) 的百分比。值越接近 1.0 代表擬合效果越完美；若小於 0 則代表模型表現比直接猜平均值還差。

2. 均方根誤差 (Root Mean Squared Error, RMSE)
RMSE = √[ (1/N) Σ(yᵢ - ŷᵢ)² ]

對誤差平方和開根號，將單位拉回與目標變數利潤同等的美元 ($)。RMSE 對極端異常值（大殘差）較為敏感。

3. 平均絕對誤差 (Mean Absolute Error, MAE)
MAE = (1/N) Σ|yᵢ - ŷᵢ|

所有樣本預測誤差絕對值的平均數，直觀代表「平均每家新創公司我們猜錯了多少美元」。對異常值抗性較高。

4. 均方誤差 (Mean Squared Error, MSE)
MSE = (1/N) Σ(yᵢ - ŷᵢ)²

線性迴歸的基礎損失函數 (Loss Function)。在數學上具備連續平滑一階可導特性，是 OLS 與梯度下降優化的核心標的。
